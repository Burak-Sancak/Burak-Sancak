## 🚀 Projects

### 🩺 [MedMNIST — Deep Feature Based Medical Image Classification](https://github.com/Burak-Sancak/medmnist-deep-features)
ViT-B/16 and ResNet-18 deep features compared with SVM and XGBoost on BreastMNIST, BloodMNIST, DermaMNIST and PathMNIST.  
Best result: **90.5% accuracy / 0.992 AUC** on PathMNIST. ViT outperformed ResNet-18 on every subset.  
`PyTorch` `ViT` `ResNet` `SVM` `XGBoost`

### 📓 Internship Journal Analyzer
Reads scanned handwritten internship journals with a vision-language model and generates a one-page summary plus missing-day and missing-signature reports.  
Flask web UI with an async backend running on Kaggle GPU.  
`Qwen3-VL-8B` `OpenCV` `Flask` `Kaggle`

### 🌧️ Clogged Storm Drain Detection from Vehicle Cameras *(TÜBİTAK 2209-A — under review)*
Research proposal as principal investigator. Drains are detected with YOLO in footage from GPS-tagged cameras on waste collection trucks, U-Net segmentation estimates the clogged area, and results are turned into a location-based maintenance priority map.  
`YOLO` `U-Net` `Computer Vision`

### 🔧 [RV32I Toolchain & FPGA Integration](https://github.com/Burak-Sancak/rv32i-toolchain-fpga)
Assembler and linker for the RV32I (RISC-V) instruction set, written from scratch.  
Generated code verified on Tang Nano 9K FPGA hardware.  
`Assembly` `RISC-V` `Verilog` `FPGA` `System Programming`

### 🏛️ [TarihinSesi — Android Audio Guide](https://github.com/Burak-Sancak/TarihinSesi)
Audio guide app for historical and cultural sites with geofencing and text-to-speech narration.  
`Android` `Firebase Firestore` `Google Maps` `Geofencing` `ElevenLabs TTS`

### 🔊 [Audio Noise Filtering](https://github.com/Burak-Sancak/audio-noise-filtering)
Classical signal processing pipeline (Butterworth + spectral subtraction) on 549 audio pairs.  
**78% MSE reduction** without any ML library.  
`Python` `Signal Processing`

### 🌱 [Renewable Energy Forecast — Turkey (2005–2030)](https://github.com/Burak-Sancak/renewable-energy-forecast-turkey)
Multivariate Linear Regression model predicting Turkey's renewable energy ratio up to 2030.  
`Python` `scikit-learn` `Pandas`

### 🚗 [License Plate Validator — DFA](https://github.com/Burak-Sancak/license-plate-recognition)
